# Figure 1 source

`build_v3.js` is the authoritative source for the camera-ready Figure 1.
It generates the three-zone mechanism diagram used in
`../DPES_Figure1_v2.pdf` and its editable PowerPoint counterpart.

`build_v2.js` and `build_figure1_v2.mjs` are retained only as provenance for
earlier drafts and should not be used to regenerate the camera-ready figure.
